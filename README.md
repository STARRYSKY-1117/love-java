# README
 
项目介绍
 
本项目为 Java Swing 趣味绘图小程序，通过数学爱心参数方程实现动态粒子爱心动画。程序以黑色为背景，使用随机粉色粒子拼接成跳动爱心，并展示“Love You、爱你一万年”文字效果，适合 Java 图形编程入门练习。
 
技术实现
 
- 基于 Java AWT + Swing 原生图形库开发
- 使用爱心心脏线参数方程计算坐标点位
- 利用三角函数、随机数生成粒子扩散效果
- 通过尺寸缩放与线程休眠实现爱心跳动动画
 
运行环境
 
- JDK 8 及以上
- 无需第三方依赖，纯原生 Java 代码
 
运行方法
 
1. 编译： javac love.java 
2. 运行： java love 
 
功能说明
 
1. 程序自动居中弹出窗口
2. 动态生成粉色粒子爱心、动态跳动缩放
3. 随机粒子颜色，画面更细腻
4. 顶部展示浪漫文字特效
5. 动画循环一定次数后停止刷新
 
总结
 
本次程序运用了 Java 窗口创建、图形绘制、字体颜色设置、循环动画与数学函数绘图知识，完成了可视化动态爱心效果，巩固了Java图形界面编程基础。
